# ¿A quién?

A free, interactive introduction to Spanish indirect object pronouns. It includes a pronoun guide, everyday examples, a sentence builder, and a five-question quiz.

Open `index.html` in a browser to use it locally. No build step or dependencies are required. Speech playback uses the browser's speech synthesis support and may vary by device.

The site is published automatically to GitHub Pages whenever changes are pushed to the `main` branch using the workflow in `.github/workflows/pages.yml`.
