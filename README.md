# ¿A quién?

A five-sentence reference for Spanish indirect object pronouns. Each sentence has an English translation directly beneath it and word-by-word parts of speech. The indirect object pronoun is highlighted and its receiver is identified.

Open `index.html` in a browser to use it locally. Exercise 1 practices indirect object pronouns; Exercise 2 uses a shuffled four-column word bank to build five Spanish sentences from English prompts. No build step or dependencies are required.

The site is published automatically to GitHub Pages whenever changes are pushed to the `main` branch using the workflow in `.github/workflows/pages.yml`.
